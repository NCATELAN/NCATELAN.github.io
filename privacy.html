Politique de confidentialité – Gmail Multi Account

Dernière mise à jour : 18 novembre 2026

Usage

Gmail Multi Account est une application à usage strictement personnel. Elle est utilisée uniquement par son propriétaire, pour accéder à ses propres comptes Gmail.

Données accédées

Via l'API Gmail, l'application peut lire les emails, en envoyer et gérer les libellés, uniquement sur les comptes de son propriétaire.

Stockage

Les jetons d'accès sont stockés uniquement sur l'ordinateur du propriétaire. L'application n'utilise aucun serveur ni aucune base de données externe.

Traitement par un assistant IA

Lorsque le propriétaire le demande, le contenu de certains emails peut être transmis à l'assistant IA Claude (Anthropic) pour être lu, résumé ou pour rédiger une réponse.

Partage

Aucune donnée n'est vendue ni partagée à d'autres fins.

Révocation

L'accès peut être révoqué à tout moment depuis myaccount.google.com/permissions.
